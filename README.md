# Taller Pyme

Herramientas empresariales abiertas, prácticas y fáciles de entender, para pequeñas empresas,
emprendedores y personas que están empezando con la automatización.

> **Estado:** iniciativa en sus inicios. Hay **un** proyecto publicado. Todavía no hay comunidad;
> si quieres ser de las primeras personas en aportar, eres bienvenida o bienvenido.

## La idea

Muchos negocios pequeños tienen problemas reales (inventario, cobros, seguimiento de clientes)
y herramientas que cuestan demasiado, son opacas o no se pueden adaptar. Taller Pyme publica,
**una herramienta a la vez**, soluciones que:

- resuelven un problema concreto de un negocio pequeño;
- se pueden **entender** leyendo el código y la documentación;
- traen instalación, configuración y uso explicados paso a paso, en español;
- son **abiertas y reutilizables**: las puedes copiar, cambiar y adaptar a tu negocio;
- evitan servicios propietarios cuando no hacen falta, y cuando los usan lo dicen claro;
- usan IA **solo cuando aporta algo** que unas reglas simples no pueden dar;
- están pensadas para **aprender**: modificarlas es parte del uso.

## Cómo cuidamos cada proyecto

- Los datos de ejemplo son **ficticios**.
- Ninguna llave, token o dato personal vive en el repositorio.
- Lo que no se ha probado se dice que no se ha probado.
- Si un proyecto depende de un servicio de terceros, el README lo declara en la primera pantalla.
